# Prime Code

Landing page independente para apresentar um curso online e gravado de desenvolvimento web moderno. A experiência inclui uma prévia de código executável em iframe sandboxed, desafios com dicas e soluções, progresso salvo localmente e um projeto demonstrativo.

## Abrir e testar

Abra `index.html` no navegador. Não há dependências ou processo de build. O projeto de emagrecimento na pasta principal permanece separado.

Na prévia, edite HTML, CSS ou JavaScript e use **Executar prévia**. A opção de atualização ao digitar fica ligada por padrão. As missões concluídas são salvas apenas no navegador do visitante, sem conta ou envio para servidor.

## Configuração para divulgação

- O formulário está configurado para abrir uma conversa no WhatsApp informado em `script.js`; o visitante confirma o envio e os dados não são armazenados por este site. O e-mail está configurado como alternativa.
- Para matrícula e cobrança, adicione o link do checkout real aos botões de inscrição em `index.html`. A página ainda não processa pagamentos nem envia cadastros a um servidor.
- Confirme preços, data de abertura, conteúdo de cada plano, adicionais de checkout, disponibilidade do suporte, certificado e políticas de acesso/reembolso antes de divulgar ou vender. Os valores e a data atualmente exibidos estão identificados como previstos.
- Inclua trajetória e foto do instrutor somente com dados fornecidos e autorizados.
- Publique depoimentos ou projetos de alunos apenas com autorização e sem sugerir resultados que não possam ser comprovados. A demonstração incluída está marcada como exemplo ilustrativo.
- Revise o aviso de privacidade de acordo com o serviço de formulário ou backend que vier a ser conectado.

As fontes são carregadas do Google Fonts. A ilustração do globo é desenhada no próprio canvas; nenhuma imagem externa é necessária para o hero.
